## 仓库转公开（含一次历史重写）

要求是「公开」，但 `orign_pdf/围城.pdf`（14.2MB，整本）与 `围城.txt`（0.69MB，全文）
受版权保护，不能随仓库分发 —— 所以**先清历史再公开**：

1. 备份：`git bundle create .tmp/pre-public-backup-20261020-1747.bundle --all`（15MB，含书）。
2. `git filter-branch --index-filter 'git rm -r --cached --ignore-unmatch --quiet "orign_pdf/*.pdf" "orign_pdf/*.txt"' --prune-empty -- main`
   —— 17 个提交全部重写，无提交变空。
   🔴 **踩坑**：filter-branch 结束时会 `git reset --hard`，**working tree 里的源书被删了**。
   已用 `git cat-file blob <old>:<path>` 从旧提交逐字节恢复，`git hash-object` 校验与
   blob 哈希一致（`ed0842…` / `a3ef3e0…`）。下次重写历史前先 `cp` 出来，别指望 filter-branch 留情。
3. `.gitignore` 加 `orign_pdf/*.pdf|*.txt|*.epub`；README「版权说明」改写；HANDOFF 标注不入库。
4. 清理：删 `refs/original`、删 `refs/remotes/origin/main`（旧历史）、`reflog expire --all`、
   `gc --prune=now` → `.git` 从 16MB 降到 **364K**，`git log --all -- orign_pdf/*` 为空。
5. GitHub：旧仓库 **改名 `pdf2epub-archive`（仍 private，留档含源书）**；
   新建**公开**仓库 `pdf2epub`（`auto_init:false`），把干净历史推上去。
   本地远端：`origin` = 公开，`archive` = 归档。

⚠️ 为什么不用 force-push 覆盖旧仓库：GitHub 不会因为 force-push 就回收对象，
旧提交仍可按 SHA 访问 —— 只有**新建仓库**才能保证历史里真的没有原文。

独立核验（`git clone --mirror` 公开仓库后）：18 个提交、历史里**没有任何 `orign_pdf` 文件**、
最大 blob 60KB（`common.py`）、总体积 334K。
