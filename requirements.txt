# 本项目依赖声明
#
# 重建环境：
#   python -m venv .venv
#   .venv/Scripts/python.exe -m pip install -r requirements.txt
#
# 自检：
#   .venv/Scripts/python.exe scripts/check_rapidocr_env.py   # OCR 环境
#
# ⚠️ openvino 必须单独列出：rapidocr 3.x **不把推理后端作为依赖**（也没有 extras），
#    只装 rapidocr 会在运行时抛 `ImportError: xxx is not installed.`。
#    本项目固定用 OpenVINO（CPU），比 onnxruntime 快约 2×，输出逐字一致。
#    🔴 **绝对不要装 onnxruntime** —— 保持"未安装"状态才能证明推理确实走 openvino
#    （装了就有静默回退空间，配置里写 openvino 也可能实际跑在 onnxruntime 上）。

# ---- 直接依赖 ----

pymupdf==1.28.2          # PDF 渲染（pipeline/split_pages.py）

                         # ⚠️ 版本敏感：pixmap_size() 依赖 pymupdf 的取整行为（ceil），换版本要重跑回归矩阵。
